# 2 本文使用的深度学习模型（正文稿）

## 2.1 深度学习代理建模基本思路

本文将阻尼钢框架在地震作用下的最大层间位移角预测问题表述为监督学习回归任务。对于任一分析样本，其输入信息可概括为三类：第一类为地震动输入，包括原始加速度时程及其派生的时频表达；第二类为结构参数，包括楼层数、结构几何尺寸、质量、刚度、强度及周期等能够反映结构动力特性的变量；第三类为阻尼器布置特征，用于描述附加耗能装置在不同楼层中的空间分布。模型输出为给定结构在给定地震动作用下的最大层间位移角，即本文统一采用的预测目标 `max_drift_ratio_raw`。

与直接开展非线性时程分析不同，深度学习代理模型并不显式求解结构运动方程，而是利用有限元分析生成的数据样本学习输入变量与结构响应之间的映射关系。设第 \(i\) 个样本的地震动信息、结构与阻尼器标量特征分别记为 \(x_i\) 和 \(s_i\)，对应的最大层间位移角记为 \(y_i\)，则代理模型可表示为

\[
\hat{y}_i = f_\theta(x_i, s_i),
\]

其中，\(f_\theta(\cdot)\) 为待训练的神经网络模型，\(\theta\) 表示模型参数，\(\hat{y}_i\) 为模型预测值。训练过程的基本目标是通过最小化预测值与有限元分析结果之间的误差，使模型能够在未参与训练的样本上保持较好的泛化能力。

本文关注的并不是完整响应时程重建，而是面向工程需求参数的峰值响应快速预测。因此，所采用的深度学习模型需要在两方面取得平衡：一方面，模型应具有足够的非线性表征能力，以捕捉地震动非平稳性、结构参数变化和阻尼器布置之间的耦合作用；另一方面，模型又应保持相对清晰的输入结构和可比较的实验设置，以便与传统机器学习基线和不同深度模型进行公平比较。基于这一考虑，本文选取 LSTM、WaveNet 和 2D-CNN 作为主要深度学习模型，并在此基础上构建多模态 2D-CNN 融合模型，用于系统考察原始时程、时频图像和结构标量特征在最大层间位移角预测中的作用。

## 2.2 LSTM 模型

长短期记忆网络（Long Short-Term Memory, LSTM）是循环神经网络的重要变体，其核心思想是在循环状态传递过程中引入门控机制，以缓解普通循环神经网络在长序列训练中容易出现的梯度消失或梯度爆炸问题。对于地震动加速度时程这类具有明显时间相关性的输入信号，LSTM 能够沿时间步逐步更新隐状态，并在一定程度上保留与结构响应相关的历史信息。

在 LSTM 单元中，遗忘门、输入门和输出门共同控制信息的保留、写入和输出。其基本更新过程可概括为

\[
f_t = \sigma(W_f[h_{t-1}, x_t] + b_f),
\]

\[
i_t = \sigma(W_i[h_{t-1}, x_t] + b_i),
\]

\[
\tilde{c}_t = \tanh(W_c[h_{t-1}, x_t] + b_c),
\]

\[
c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t,
\]

\[
o_t = \sigma(W_o[h_{t-1}, x_t] + b_o),
\quad
h_t = o_t \odot \tanh(c_t),
\]

其中，\(x_t\) 为第 \(t\) 个时间步的输入，\(h_t\) 和 \(c_t\) 分别为隐状态和细胞状态，\(\sigma(\cdot)\) 表示 Sigmoid 函数，\(\odot\) 表示逐元素乘法。通过上述门控结构，LSTM 可以在较长时间范围内选择性保留对预测目标有贡献的信息。

在本文任务中，LSTM 主要用于处理原始地震动时程。地震动序列经统一长度处理后输入时序分支，模型从加速度幅值变化、强震持续过程以及能量集中时段中提取时序特征。考虑到最大层间位移角不仅受地震动本身影响，还与结构周期、质量、楼层数和阻尼器布置等因素密切相关，本文的 LSTM 实现并非仅依赖单一波形输入，而是进一步引入结构与地震动标量特征作为辅助信息。时序分支提取的序列表示与标量分支提取的结构特征在表示层进行融合，最终通过回归头输出最大层间位移角预测值。

从模型对比角度看，LSTM 在本文中主要承担时序深度学习基线的作用。通过将其与 WaveNet、2D-CNN 以及多模态 2D-CNN 进行比较，可以判断直接利用原始地震动序列进行建模是否足以支撑峰值响应预测，也可以进一步分析循环神经网络在未见地震波条件下的泛化表现。

## 2.3 WaveNet 模型

WaveNet 是一种基于一维卷积的深度时序模型，其关键特征是采用扩张卷积扩大时间感受野。与 LSTM 依赖递归状态传递不同，WaveNet 通过卷积运算并行处理序列数据，因此在较长地震动输入上具有较高的计算效率。同时，扩张卷积能够在不显著增加参数量的情况下覆盖更长的时间范围，有利于捕捉地震动中不同时间尺度的变化特征。

对于一维序列输入 \(x\)，扩张卷积可表示为

\[
y_t = \sum_{k=0}^{K-1} w_k x_{t-dk},
\]

其中，\(K\) 为卷积核长度，\(d\) 为扩张率。当扩张率随网络层数逐层增大时，模型的感受野能够快速扩展，从而同时利用短时局部波动和较长时间范围内的地震动演化信息。WaveNet 通常还会结合门控激活、残差连接和跳跃连接，以提高深层时序卷积网络的训练稳定性和表达能力。

在本文中，WaveNet 被用于建立另一类原始地震动序列模型。模型首先对地震动序列进行通道映射，然后通过多层扩张门控卷积模块提取时序特征。为将变长或高维时序表示转化为固定维度向量，模型可采用平均池化、最大池化或注意力池化等方式汇聚全局信息。与 LSTM 类似，WaveNet 分支提取的波形特征随后与结构参数、地震动统计特征和阻尼器布置特征进行融合，并通过回归输出层预测最大层间位移角。

WaveNet 在本文中的作用主要体现在两个方面。首先，它可作为与 LSTM 对照的非递归时序模型，用于分析卷积式时序建模是否更适合处理地震动信号。其次，WaveNet 的扩张卷积结构能够显式覆盖多个时间尺度，有助于检验地震动持续时间、能量释放过程和频率非平稳性等因素是否能够通过原始序列输入被有效学习。通过 LSTM 与 WaveNet 的对比，本文可以更清楚地判断不同一维时序深度模型在阻尼钢框架峰值响应预测中的适用性。

## 2.4 2D-CNN 模型

二维卷积神经网络（Two-Dimensional Convolutional Neural Network, 2D-CNN）主要用于处理图像或类图像数据。对于地震动输入而言，原始加速度时程是一维信号，但其结构响应效应不仅取决于幅值大小，还与频率成分、能量分布和持续时间密切相关。因此，将地震动转换为时频图像后再进行卷积建模，是一种能够同时表达时间信息和频率信息的输入方式。

本文采用地震动小波时频图（scalogram）作为 2D-CNN 的主要图像输入。小波时频图能够描述地震动能量在不同时间和频率尺度上的分布情况，相比单一强度指标或简单统计特征，其包含了更丰富的非平稳特征。对于阻尼钢框架体系而言，结构响应不仅受地震动峰值强度影响，还与地震动主频、结构自振周期及阻尼器耗能过程之间的匹配关系有关。因此，时频图像有助于模型从二维局部模式中提取与结构响应相关的特征。

在 2D-CNN 中，卷积层通过局部卷积核提取图像中的时间-频率局部模式，池化层用于降低特征图尺度并增强局部平移鲁棒性，归一化和激活函数则用于提高训练稳定性和非线性表达能力。经过多层卷积与池化后，模型可将高维时频图像映射为固定维度的图像特征向量，再通过全连接层或回归头得到最大层间位移角预测值。

本文设置 2D-CNN 模型的目的，是检验地震动时频图像表达相对于原始时程表达的潜在优势。若 2D-CNN 能够取得优于 LSTM 和 WaveNet 的预测表现，则说明时频图像中包含的局部时间-频率模式对最大层间位移角预测具有较强贡献；反之，则表明仅将地震动转换为二维图像并不足以完全描述阻尼钢框架响应，还需要进一步引入结构参数和阻尼器布置等辅助信息。

## 2.5 多模态 2D-CNN 融合模型

多模态 2D-CNN 是本文重点考察的深度学习框架。该模型在时频图像分支的基础上进一步引入结构参数、地震动统计特征和阻尼器布置特征，从而同时利用图像模态和表格模态的信息。其基本出发点在于：地震动时频图能够表征输入激励的时间-频率演化，而结构标量特征和阻尼器布置特征则决定了结构对同一地震动输入的动力响应方式。仅使用其中任一模态，都可能造成信息不完整。

具体而言，图像分支以小波时频图为输入，通过多层二维卷积模块提取地震动时频特征。标量分支则以结构参数、地震动强度与统计特征、阻尼器布置展开特征等作为输入，通过多层感知机或残差式标量编码器得到低维嵌入表示。阻尼器布置特征在该模型中具有重要意义，因为不同楼层阻尼器的安装位置会改变结构附加耗能分布，并进一步影响各楼层变形集中程度。将该类布置信息显式纳入标量分支，有助于模型区分几何参数相近但耗能体系不同的结构样本。

为了提高图像特征与标量特征之间的交互能力，本文多模态模型采用条件调制与门控融合思想。对于卷积分支中的中间特征图 \(F\)，可利用标量特征生成调制参数 \(\gamma(s)\) 和 \(\beta(s)\)，并对图像特征进行条件化变换：

\[
F' = \gamma(s) \odot F + \beta(s).
\]

这种特征线性调制机制使得结构参数和阻尼器布置能够直接影响图像特征提取过程。换言之，同一地震动时频图在不同结构体系下不应被解释为相同的响应风险，模型需要根据结构动力特性对图像特征进行条件化编码。

在最终融合阶段，模型将图像分支输出与标量分支输出进行联合表达。简单拼接虽然能够保留两类特征，但对模态间高阶关系的刻画能力有限。因此，本文采用门控双线性融合方式，使图像特征和标量特征能够相互调节，并通过乘性关系表达跨模态耦合。该设计有助于刻画地震动频谱特征、结构周期特征和阻尼器布置之间的非线性组合效应。

多模态 2D-CNN 的输出层为回归预测头，直接给出最大层间位移角估计值。考虑到最大层间位移角数据通常具有一定长尾分布，高漂移样本在训练集中占比较低，模型训练时还可结合样本权重或尾部误差惩罚，以降低高响应区间被主密度样本主导的风险。不过，尾部修正策略本身并不能替代数据覆盖；若训练集中缺少足够的高漂移样本，模型仍可能出现系统性低估。因此，本文后续实验不仅报告整体误差指标，还将进一步分析不同漂移区间下的误差表现。

总体而言，多模态 2D-CNN 的优势在于能够同时利用地震动的高维时频表达和结构体系的物理描述。该模型既保留了 2D-CNN 对图像局部模式的自动特征提取能力，也通过标量分支引入了工程上具有明确含义的结构与阻尼器信息。因此，它是本文用于验证多源异构输入有效性的核心模型。

## 2.6 本章模型设置与后续实验关系

本章介绍的 LSTM、WaveNet、2D-CNN 和多模态 2D-CNN 分别对应不同的输入表达和特征学习方式。其中，LSTM 和 WaveNet 主要从原始地震动序列中学习时序特征；2D-CNN 主要从地震动时频图像中学习时间-频率局部模式；多模态 2D-CNN 则在图像表达基础上融合结构参数、地震动统计特征和阻尼器布置特征。通过这些模型的对比，可以系统分析不同输入模态和不同网络结构对最大层间位移角预测性能的影响。

为保证比较的公平性，后续实验中各深度学习模型均采用相同的预测目标，即最大层间位移角 `max_drift_ratio_raw`。训练集、验证集和测试集按照统一规则划分，且数据预处理参数仅在训练集上拟合，再应用于验证集和测试集。模型评价不仅包括 \(R^2\)、MAE、RMSE 和 MAPE 等整体指标，还包括未见地震波条件下的泛化能力分析，以及按漂移区间划分的误差统计。

需要强调的是，本章的重点在于说明本文所使用深度学习模型的基本原理和建模作用，而不是对最终预测结果作出结论。模型性能、不同算法之间的定量比较、输入模态消融以及高漂移区间误差分析，将在后续实验与结果分析章节中展开。通过这样的章节安排，可以避免在模型介绍部分过早引入实验结论，同时为后文的统一对比提供清晰的方法基础。
