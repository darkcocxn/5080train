# 1 引言

## 1.1 研究背景与问题提出

非线性时程分析（Nonlinear Time-History Analysis, NLTHA）是工程结构抗震响应评估与基于性能的抗震设计（PBD）中的核心方法，能够较准确地反映结构在复杂地震荷载下的塑性分布与非线性行为。然而，在面对大样本参数敏感性分析、区域地震风险评估以及结构方案初步筛选等多方案、大量地震动输入任务时，直接开展大规模有限元分析面临着严峻的计算成本瓶颈。因此，开发既能保证一定预测精度，又能实现快速推断的结构响应代理模型（Surrogate Model），已经成为地震工程与深度学习交叉领域的一项现实需求。

在各类工程需求参数中，最大层间位移角是反映结构在地震中宏观变形与整体破坏程度的关键性指标。各国现行主流抗震设计规范（如中国的《建筑抗震设计规范》GB 50011、美国的ASCE 7与FEMA P-58性能化准则、以及欧洲抗震规范Eurocode 8等）均将其强制作为评估结构损伤状态、控制非结构构件破坏以及保障生命安全的控制参数。当前针对该类峰值响应预测的研究多集中于普通钢框架或混凝土结构。而对于附带耗能装置的阻尼钢框架体系，阻尼器的空间布置方案、地震动能量的时频演变特征以及主体结构参数之间存在着强烈的非线性耦合关系。这种参数的复杂互动，使得传统依赖单一形式特征输入（如简单的烈度指标或响应谱参数）的预测模型，难以精准且稳定地刻画结构的极值变形规律。此外，现有研究在评价代理模型时，往往过度依赖或几乎仅局限于全局相关系数（$R^2$）或均方根误差（RMSE）等整体统计指标，这极易掩盖模型在关键的中高漂移区间（即罕遇地震下的大变形或破坏区）存在的系统性低估问题。如果缺乏对预测误差分层（尤其是高风险尾部区间）的细致推敲与讨论，将给工程结构的真实风险识别带来隐患。

## 1.2 现有研究的瓶颈与不足

从建模方法的发展历程来看，结构地震响应预测领域已取得了丰硕的成果，但在特定复杂场景下面临的挑战促使算法设计不断演进。早期与部分近期的研究主要采用广义线性回归[11,12]、响应面分析[13]以及多层感知机（MLP）[15-17]、随机森林、极端梯度提升树（XGBoost）[20,21]等表格型机器学习算法来预测结构峰值响应。这些模型由于在训练及推理效率上具有显著优势，在概率地震需求分析与区域脆弱性评估中得到了广泛应用。然而，这类模型在应用时通常首选峰值地面加速度（PGA）、谱加速度（Sa）等单一或一组离散的烈度指标（IMs）作为激振输入[18]，往往需要借助先验工程经验进行统计特征的手动提取。这种降维表征方式极易导致地震动原始高维时序信息（如强震持续时间、频率非平稳性与能量释放历程）的丢失[19]，在充分挖掘复杂地震波导致结构深层塑性破坏的潜能方面，仍有待进一步深化。

为了突破传统统计特征构建的局限，近年来大量前沿研究开始直接利用未人为压缩的原始时序或短时傅里叶变换（STFT）下的时频谱数据。例如，以 Zhang 等[22]和 Luo 等[23]为代表的研究引入了长短期记忆网络（LSTM）与门控循环单元（GRU）等一维序列网络来预测非线性结构的地震响应时程；同时，Oh 等[24]与 Wu 等[25]则验证了 WaveNet 与二维卷积神经网络（2D-CNN）在处理结构动力学演化特征及捕捉损伤累积效应上的巨大潜力。尽管这些基于原始数据的深度学习研究取得了突破性进展，但聚焦于本文关注的带有耗能阻尼设施的复杂钢框架系统最大层间位移角预测任务，现有文献的专门探讨仍相对有限。首先，在网络输入与架构设计上，多数现有深度模型仍依赖单一模态的数据输入（纯时序或纯图像），对于如何高效、自适应地融合多源跨域数据（如表征地震动演化的二维时频图、控制刚度分布的阻尼器拓扑矩阵、以及结构固有物理属性的离散标量特征），目前地震工程领域仍缺乏类似特征线性调制（FiLM）或多源门控网络等成熟的跨模态深度交互（Cross-modal Interaction）方案[26,27]。其次，在模型泛化性评估环节，多数最新文献常局限于在同一批地震动集合内部进行简单的“随机打乱插值测试”，而针对完全没见过的异源强震，即极具防灾意义的“未见地震波（Unseen Ground Motions）”外推检验（Extrapolation）依旧缺乏严格的论证[28]。最后，面对罕遇激振导致结构产生大变形这一最关键的防灾痛点，由于高漂移样本在数据集中通常服从极端的长尾分布（Long-tail Distribution），常规模型极易被庞大的低漂移样本主导，目前领域内鲜有研究针对“极高大漂移尾部区段（Tail）”因样本稀疏而引发的极值预测系统性低估展开专门的客观误差解构与对策分析[29,30]。

## 1.3 本文的研究目标与主要贡献

为了填补上述研究空白，本文建立了一种立足阻尼钢框架最大层间位移角快速准确预测的多模态代理建模框架。该体系以多源异构数据为切入点，针对性地设计了引入特征线性调制（FiLM）机制与门控双线性融合（Gated Bilinear Fusion）模块的二维卷积神经网络（2D-CNN）作为主模型。该架构能够深度并系统性地融合表征地震动高维演化特征的短时傅里叶变换（STFT）时频谱图、描述结构整体动力学特性的标量参数（如自振周期、高宽比、质量分布等）、以及体现耗能机制的空间阻尼器布置方案。

为严格验证所提架构的科学有效性及其工程适用边界，本文基于 OpenSees 平台生成的大规模阻尼钢框架弹塑性非线性时程数据集，在统一的波级别数据集划分（确保测试集为独立的未见地震波）与多维评价体系（$R^2$、MAE、RMSE、MAPE）下，展开了全面严谨的基准测试验证。

本文的核心贡献可具体总结为以下四点：

（1）**提出了一种新颖的多源异构数据融合 2D-CNN 代理算法架构**。为了解决异构特征融合的痛点，模型内部创新性地引入了特征线性调制（FiLM）机制使得离散标量参数能够动态调控卷积视觉提取通路，并辅以门控双线性融合模块（Gated Bilinear Fusion）实现表示层的高阶跨模态交互，有效克服了高维度波形图像特征与低维离散物理参数之间非线性耦合困难的技术瓶颈。
（2）**建立了横跨多种前沿算法的全面基准测评实验体系**。打破了以往文献孤立讨论某一种深度模型的局限，在彻底对齐数据提取的条件下，将本文所提主模型与当代领先的表格型强基线集群（MLP、Random Forest、XGBoost、LightGBM、CatBoost）以及主流序列神经网络（LSTM、WaveNet）进行了一体化、透明化的交叉量化比对，清晰界定了各类算法在计算耗时与预测精度权衡下的能力边界与优劣象限。
（3）**开展了面向绝对“未见地震波”（Unseen GM）场景的苛刻鲁棒性剖析**。有别于传统文献中采用的简单随机全打乱插值测试结构，本项研究专门依据地震波动记录名称进行了严格的数据级隔离与切分（Wave-level Split），系统论证了所提引入 STFT 高维时频特征的融合框架能够大幅增强替代模型对异源未知强震荷载的外推泛化特性。
（4）**拓展了兼顾整体评价与高漂移极值区（Tail）识别的系统认知视角**。针对罕遇激振导致大变形这一工程避险核心痛点，本文突破了传统研究单求全局统计误差最低的盲区，深度解构了常规算法在数据长尾区间不可避免的系统性低估现象。同时结合研究中探索设计的尾部分类辅助（Tail Classification Aux）与概率门控修正（Prob-Gated Correction）机制等进阶策略思路，为随后基于物理先验修正（Physics-Informed）和边界极限调优的代理模型纵深发展提供了极具启发意义的前沿参照。
