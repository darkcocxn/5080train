# 摘要

## 0.1 第一篇参考文献摘要原文

来源文件：`参考文献.md`

在地震荷载作用下，预测土木工程结构的非线性时程响应仍然是地震工程领域的一项关键任务。本文探讨了开发三种深度学习（DL）模型——长短期记忆（LSTM）、WaveNet以及2D卷积神经网络（CNN）——以预测三座基准结构的地震响应时程的潜力，这些结构包括单自由度系统、钢制建筑框架以及多构件桥梁结构。LSTM此前已得到发展并被用作参考模型，而WaveNet和2D CNN（即其处理数据时采用耦合的时间-频率维度）则是本研究中新近开发的模型。此外，一项新颖的贡献在于将WaveNet的最后一层替换为LSTM层，这一改进显著提升了模型性能。本文介绍了这些DL模型的方法学背景，并对模型架构与超参数、评估指标列表，以及用于数据生成的地面运动（GM）套件进行了详细讨论。为了开展非线性时程分析，我们构建了高保真数值模型，生成大量运动响应对，用于训练、验证和测试这些DL模型。LSTM和WaveNet直接利用时间序列GM输入和地震响应输出来训练模型，而CNN则通过对经过短时傅里叶变换（STFT）转换后的时频谱图进行推断。通过对比在单一测试GM下的确定性预测结果，以及六项评估指标的概率分布，对这三种DL模型进行了深入研究。此外，我们还借助不同训练样本和模型架构下的敏感性分析，进一步考察了这些模型的准确性、效率与鲁棒性。本研究的成果为业界提供了可靠的参考依据，助力各方充分利用这三种DL模型，实现可靠且高效的时程响应预测——这对于完成前沿研究或实际应用任务至关重要，例如区域地震风险评估以及基于性能的抗震设计。

## 0.2 与你项目的对比

- 参考文献的任务是预测多类结构的非线性地震响应时程，而你当前项目聚焦于阻尼钢框架的单一峰值指标 `max_drift_ratio_raw`。
- 参考文献以 `LSTM / WaveNet / 2D-CNN` 为主对比组，你的项目在此基础上还加入了 `MLP / Random Forest / XGBoost / LightGBM / CatBoost` 等传统强基线。
- 参考文献强调“响应时程预测”，你的项目更适合强调“最大层间位移角快速代理预测”。
- 参考文献使用三类基准结构，你的项目则更适合聚焦单一结构体系下的多模型比较。
- 参考文献的摘要同时强调准确性、效率和鲁棒性；你的摘要还应额外强调未见地震波泛化能力，以及高漂移区间存在系统性低估这一边界条件。

## 0.3 你的摘要写作骨架

### 背景

- 非线性时程分析计算成本高，限制了阻尼钢框架在大样本参数分析和快速评估场景中的应用。
- 最大层间位移角是结构抗震性能评估中的关键工程需求参数，具有明确工程意义。

### 方法

- 构建融合地震波时频图、结构参数、地震动统计特征和阻尼器布置特征的多模态代理模型。
- 采用多模态 2D-CNN 作为主模型，并与 LSTM、WaveNet、MLP、Random Forest、XGBoost、LightGBM 和 CatBoost 进行统一对比。

### 结果

- 给出主模型测试结果：`R2=0.907476`、`MAE=0.000288331`、`RMSE=0.000412856`、`MAPE=17.16%`。
- 说明主模型在当前中低漂移测试集上取得了最优整体表现。
- 同时指出模型在更高漂移区间仍存在明显低估，高漂移识别能力仍有不足。

### 结论

- 当前模型适合中低漂移范围内的快速代理预测。
- 若面向高漂移风险识别与屈服后响应预测，仍需补充更均衡的 tail 样本并进一步优化监督设计。

## 0.4 你的摘要初稿

非线性时程分析能够较准确地评估结构在地震作用下的响应，但其较高的计算成本限制了其在大样本参数分析、快速风险评估和方案筛选中的应用。针对阻尼钢框架最大层间位移角快速预测问题，本文提出一种融合地震波时频图、结构参数、地震动统计特征和阻尼器布置特征的多模态代理建模方法，并以多模态 2D-CNN 作为主模型。为系统评估该方法的有效性，本文在统一数据划分和统一评价体系下，将主模型与 LSTM、WaveNet、MLP、Random Forest、XGBoost、LightGBM 及 CatBoost 等模型进行了对比。结果表明，主模型在当前测试集上取得了较优的整体表现，测试集 `R2` 达到 `0.907476`，`MAE` 为 `0.000288331`，`RMSE` 为 `0.000412856`，`MAPE` 为 `17.16%`，说明多模态输入能够有效提升中低漂移范围内的响应预测精度。进一步分析表明，虽然模型在整体指标上表现较好，但在中高漂移区间仍存在系统性低估现象，高漂移阈值识别能力仍有不足。总体而言，本文方法能够为阻尼钢框架中低漂移响应的快速代理预测提供支持，但面向高漂移风险识别和屈服后响应预测时，仍需通过补充 tail 样本和优化训练策略进一步提升模型性能。
