## 4. 主要结果

- p95 高响应尾部 MAE 最低模型：`wavenet`，p95 MAE = `0.000720476`。
- `target >= 0.005` 阈值召回最高模型：`lstm`，recall = `0.714685`。
- `target >= 0.005` 危险低估率最低模型：`lstm`，dangerous underprediction rate = `0.285315`。
- locked test 中 `target >= 0.005` 样本数为 `143`；`target >= 0.010` 样本数为 `0`。

这些结果说明：平均误差最优、p95 tail 最优、阈值召回最高、危险低估率最低不一定是同一个模型。论文必须把“整体精度”和“工程安全阈值行为”分开写，不能只用 MAE 支撑安全性。

## 5. 安全主张边界

当前 locked test 缺失以下高风险覆盖：target >= 0.010, target >= 0.015, target >= 0.020, steel01_yielded == 1。

因此 TODO7 现在可以支持的表述是：模型在当前 locked test 覆盖的轻中度 tail 和 `target >= 0.005` 阈值上完成了显式危险低估量化。不能支持的表述是：模型已经证明在 `target >= 0.010/0.015/0.020`、主体屈服或接近失效工况下可靠。若论文要写强工程安全 claim，必须进入 TODO10 构造 high-drift / yielded / OOD benchmark。
