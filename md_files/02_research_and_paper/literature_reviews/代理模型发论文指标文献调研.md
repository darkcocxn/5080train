## 3. 数据分布对结论的影响

当前训练实际使用的 `drop-split-rank-top5drift` 数据分布如下：

| split | 样本数 | unique waves | drift mean | drift p95 | drift max | `>=0.005` | `>=0.010` | `steel01_yielded` | `steel02_yielded` |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| train | 67260 | 163 | 0.002842 | 0.006471 | 0.008243 | 9268 | 0 | 0 | 44840 |
| val | 3420 | 17 | 0.002589 | 0.009549 | 0.014465 | 422 | 152 | 152 | 2111 |
| test | 3116 | 14 | 0.001970 | 0.004911 | 0.007362 | 143 | 0 | 0 | 2048 |

关键问题：

1. 训练集没有 `>=0.010` 样本，测试集也没有。
2. 验证集有 152 条 `>=0.010`，且这些样本对应 `steel01_yielded=1`，但 train/test 中 `steel01_yielded=1` 都是 0。
3. 因此，`2dcnnv9` 的 `0.010/0.020/0.030` tail 分类头没有训练正样本可学，保守 tail 选择无法真正发挥作用。
4. 当前高 R2 主要说明中低漂移区间拟合较好，不能外推为极端响应预测可靠。

这个数据分布决定了论文表述必须克制：可以强调快速代理预测和未见波测试，但不能把当前结果包装成高损伤状态识别模型。

## 4. 与已发表论文的指标对照

结构抗震响应代理模型没有固定的“达到某个指标即可发表”的硬标准。能否发表主要取决于三点：

1. 是否解决明确工程问题，例如替代部分 OpenSees 非线性时程分析、快速预测最大层间位移角、辅助阻尼器布置筛选。
2. 是否在未见地震波、未见结构参数组合上具有可信泛化。
3. 是否有方法学贡献，例如多模态输入、时频图建模、阻尼器布置特征、tail-aware 损失、消融实验和强基线对比。

## 5. 当前结果是否足够发表

### 5.1 可以支撑的论文定位

当前 `2dcnnv2` 的测试结果：

```text
R2 = 0.907476
MAE = 0.000288331
RMSE = 0.000412856
MAPE = 17.16%
```

这个结果已经达到“较稳妥工程应用论文”的整体指标线。若论文定位为：

```text
基于地震波小波时频图、结构参数和阻尼器布置特征的多模态代理模型，
用于快速预测 3-7 层钢框架/阻尼结构在中低漂移区间的最大层间位移角。
```

那么当前结果可以写。它的优势是：

- 全局 R2 超过 0.90；
- MAE/RMSE 很低，工程量纲上误差小；
- MAPE 低于 20%；
- 使用未见地震波测试；
- 输入包含地震动时频图、结构参数、地震动统计特征和阻尼器布置。

### 5.2 不建议当前直接主打的定位

不建议现在把论文主标题或摘要写成：

- 高漂移危险状态识别；
- 屈服后响应精确预测；
- 极端地震响应 tail risk 预测；
- 高精度代理模型优于所有传统 ML。

原因是：

- 测试集中没有 `>=0.010` 样本；
- 训练集中也没有 `>=0.010` 样本；
- `>=0.005` 的 F1 只有约 0.68；
- `0.005-0.010` 区间欠预测率为 81.8%；
- 还没有完成 XGBoost、LightGBM、CatBoost 等强基线对比。

### 5.3 指标层级判断

| 评价等级 | 建议指标 | 当前 v2 是否达到 |
|---|---|---|
| 基本可投 | R2 >= 0.85，MAE <= 0.0015-0.0020，RMSE <= 0.0025-0.0040，MAPE <= 25% | 达到 |
| 比较稳妥 | R2 >= 0.90，MAE <= 0.0010，RMSE <= 0.0015-0.0020，MAPE <= 20% | 整体达到 |
| 强结果 | R2 >= 0.94-0.96，MAE <= 0.0007，RMSE <= 0.0010-0.0015，MAPE <= 10%-15%，tail F1/Recall 高 | 整体 MAE/RMSE 达到，R2/MAPE/tail 不足 |

因此，当前最稳妥的结论是：

```text
当前结果已经具备工程应用型代理模型论文基础；
若要冲击高精度或高影响力期刊，需要补强强基线、tail 覆盖和消融实验。
```

## 6. 写论文时应报告哪些指标

不建议只报告 R2、MAE、RMSE、MAPE。当前任务必须区分“平均响应预测”和“高响应风险预测”。

建议论文主表报告：

| 指标 | 目的 |
|---|---|
| R2 | 整体拟合优度 |
| MAE | 工程量纲下的平均误差 |
| RMSE | 对较大误差更敏感 |
| MAPE 或 SMAPE | 相对误差，但需说明低漂移样本会放大 MAPE |
| Bias | 判断是否系统性高估/低估 |
| 分漂移区间 MAE/Bias | 暴露中高漂移误差 |
| 阈值 Precision/Recall/F1 | 判断是否能识别高响应状态 |
| 按楼层数分组误差 | 证明 3-7 层泛化 |
| 按阻尼器布置分组误差 | 证明布置特征有效 |
| 按 wave cluster 或 wave intensity 分组误差 | 证明未见地震波泛化 |

当前文稿中建议单独放一张表说明：

```text
当前测试集无 >=0.010 样本，因此 >=0.010 / >=0.020 的危险状态识别不作为本文主要结论。
```

这样表述更严谨，也能降低审稿人抓住 tail 分布问题质疑整篇工作的风险。

## 7. 多算法对比建议

### 7.1 必须新增的传统 ML 强基线

为满足同类论文常见要求，建议优先实现以下模型，统一使用当前 63 个标量特征，不使用小波图像：

| 算法 | 推荐程度 | 原因 |
|---|---|---|
| Linear/Ridge | 必做 | 最低线性基线，证明任务非线性 |
| Random Forest | 必做 | 结构工程论文中常见、稳定、可解释 |
| Extra Trees | 必做 | 常在表格回归中强于 RF，可作为强树基线 |
| XGBoost | 必做 | 同类地震响应预测文献高频强基线 |
| LightGBM | 建议 | 训练快，适合大表格数据 |
| CatBoost | 强烈建议 | Samadian et al. 中 CatBoost 是最终代理模型，审稿人容易接受 |
| MLP | 必做 | 与当前 CNN 的标量神经网络分支形成公平对比 |

### 7.2 深度学习对比

如果论文要突出小波时频图和多模态融合，建议再加入：

| 算法 | 输入 | 目的 |
|---|---|---|
| scalar-only MLP | 63 个标量特征 | 证明仅标量特征能达到什么水平 |
| image-only 2D CNN | scalogram 图像 | 证明图像分支单独贡献 |
| 1D-CNN 或 TCN | 原始地震波时程 + 标量 | 对比时程建模 |
| LSTM/GRU 或 WaveNet | 原始地震波时程 + 标量 | 对比已发表深度时序模型 |
| 当前 multimodal 2D-CNN | scalogram + 标量 + damper layout | 主模型 |

### 7.3 消融实验

建议至少做以下消融：

| 消融项 | 目的 |
|---|---|
| 无小波图像，只用标量 | 证明图像时频信息增益 |
| 无 damper layout | 证明阻尼器布置特征必要 |
| 无 wave 派生特征 | 证明 PGA、CAV、Arias、duration、频率特征贡献 |
| 无 FiLM，仅拼接融合 | 证明标量条件调制有效 |
| 无 tail loss / 无 weighted sampler | 证明 tail-aware 训练策略贡献 |
| v2 vs v9 | 比较整体 MAE 优先和保守 tail 选择的权衡 |

## 8. 后续提升路线

### 8.1 数据优先级最高

当前瓶颈不是继续堆网络复杂度，而是 train/test 缺少真正高漂移样本。建议重新构建分层数据：

- `max_drift_ratio_raw` 分箱：`<0.001`、`0.001-0.002`、`0.002-0.003`、`0.003-0.005`、`0.005-0.010`、`>=0.010`、`>=0.020`；
- `steel01_yielded`；
- `steel02_yielded`；
- `num_floors`；
- `wave_cluster`。

目标是让 train/val/test 都覆盖高漂移和屈服状态。否则，再强的 tail loss 也没有正样本可学。

### 8.2 训练策略

在当前数据分布不变的情况下：

- 主模型继续用 v2；
- v9 作为保守 tail 消融，不建议替代 v2；
- 不建议继续加大 `0.010/0.020/0.030` 的 tail 权重，因为训练正样本为 0；
- 若只在当前 drop 数据上优化，可把临时 tail 阈值改为 `0.003/0.005/0.007`；
- 若恢复高漂移数据，再使用 `0.010/0.020/0.030` 作为工程阈值。

### 8.3 论文叙事建议

推荐论文主线：

```text
提出一种面向阻尼钢框架最大层间位移角快速预测的多模态代理模型。
模型融合地震动小波时频图、结构物理参数、地震动强度/频谱特征和阻尼器布置。
在未见地震波测试集上，当前主模型取得 R2=0.9075、MAE=2.88e-4、RMSE=4.13e-4。
```

不要把主线写成：

```text
提出高漂移危险状态预测模型。
```

除非后续补齐高漂移样本，并把 `>=0.010` 的 F1/Recall 提升到约 `0.75-0.85`。

## 9. 最终结论

1. 当前最好的主模型是 `2dcnnv2/model-nostamp-6f475c7d-train20260601-014156`。
2. `2dcnnv9/model-nostamp-6f475c7d-train20260601-024158` 是有价值的 tail-aware 对照，但当前测试集整体指标略低于 v2。
3. v2 的整体结果已经达到工程应用型论文的较稳妥水平，尤其 MAE/RMSE 很好。
4. 当前还不能主打高漂移、屈服后或极端风险预测，因为 train/test 中缺少 `>=0.010` 样本，且 `>=0.005` 的 F1 仍不高。
5. 下一步最重要的是补强多算法对比和消融实验，其次是重新做高漂移分层数据集。
6. 若目标是更强论文，建议把评价重点从“单一 R2”扩展为“未见波泛化 + 多模态消融 + 强基线对比 + tail 分层指标”。
