## 3. 为什么会得到当前训练结果

### 3.1 首要原因是数据分布，而不是网络容量

原始 `20260531-181258` 数据集分布：

| split | 样本数 | max drift | `>=0.005` | `>=0.010` | `>=0.020` | `steel01_yielded` |
|---|---:|---:|---:|---:|---:|---:|
| train | 70800 | 0.039367 | 13014 | 1858 | 145 | 1858 |
| val | 3600 | 0.024464 | 602 | 315 | 44 | 315 |
| test | 3600 | 0.041390 | 621 | 368 | 273 | 368 |

`drop-split-rank-top5drift` 数据集分布：

| split | 样本数 | max drift | `>=0.005` | `>=0.010` | `>=0.020` | `steel01_yielded` |
|---|---:|---:|---:|---:|---:|---:|
| train | 67260 | 0.008243 | 9268 | 0 | 0 | 0 |
| val | 3420 | 0.014465 | 422 | 152 | 0 | 152 |
| test | 3116 | 0.007362 | 143 | 0 | 0 | 0 |

`drop` 数据集的测试集没有 `>=0.010` 高漂移样本，也没有 `steel01_yielded=1` 样本。因此 `2dcnnv2/drop` 的高 R2 和低 MAE 是可信的中低漂移结果，但不能证明模型已经学会了高漂移、主结构屈服后的响应。

### 3.2 2dcnnv9 的 tail 设计与当前 drop 数据不匹配

`2dcnnv9` 增强了 tail 相关机制：

- tail 分类阈值从 `[0.01, 0.02]` 扩展为 `[0.01, 0.02, 0.03]`；
- 采样倍率从 `1.10` 提到 `1.25`；
- `>=0.010`、`>=0.020`、`>=0.030` 权重更高；
- 验证选择分数更重视 tail MAE、extreme tail MAE 与低估惩罚。

但在 `drop` 训练集中，`>=0.010`、`>=0.020`、`>=0.030` 的正样本数全部为 0。也就是说，v9 的 tail 分类头和高阈值低估惩罚没有有效正样本可学；验证集又存在 152 条 `>=0.010` 样本，导致验证目标与训练/测试分布不一致。最终表现就是：v9 的验证集 tail 选择更积极，但测试集整体指标反而略差于 v2。

### 3.3 原始数据集中的极端尾部仍然是主要难点

原始测试集中 `>=0.020` 有 273 条，且该区间 `2dcnnv9` 的 MAE 为 `0.009301`，Bias 为 `-0.009268`，欠预测率为 `98.9%`。这不是普通随机误差，而是系统性低估。

这和结构机理一致：OpenSees `Steel01` 是双线性钢材模型，包含运动硬化和可选各向同性硬化；`Steel02` 是 Giuffre-Menegotto-Pinto 钢材模型，包含从弹性到塑性分支的平滑转变和各向同性硬化参数。进入屈服和滞回路径依赖后，最大层间位移角对地震动持续时间、频率成分、结构周期比、阻尼器布置、强度和刚度的耦合更敏感，稀疏样本下监督回归容易向主密度区间回归。

### 3.4 训练过程也支持这个判断

`2dcnnv2/drop`：

- 训练 50 epoch；
- best epoch = 30；
- best val MAE = `0.000497610`；
- best val loss = `0.269193`；
- 训练后期 train loss 继续下降，但 val 指标基本平台化。

`2dcnnv9/drop`：

- 训练 35 epoch；
- best epoch = 19；
- best val MAE = `0.000489083`，略优于 v2；
- 但默认选用更保守的 `best_2dcnn_focus_model.pth`；
- 测试集 R2/MAE/RMSE 均略差于 v2。

`2dcnnv9/原始数据`：

- 训练 21 epoch；
- best epoch = 5；
- best val MAE = `0.000760205`；
- best epoch 很早出现，说明强 tail 权重、强采样和高尾部样本共同造成训练选择较早锁定，后续并未改善全局泛化。

## 4. 和已发表论文相比是否足够

### 4.1 简短结论

如果论文定位是：

> 基于地震波时频图、结构参数和阻尼器布置的代理模型，用于快速预测中低漂移范围的最大层间位移角。

那么 `2dcnnv2/drop` 的结果已经具备写论文的基础：`R2=0.9075`、`MAE=2.88e-4`、`RMSE=4.13e-4`、`MAPE=17.16%`。

但如果论文定位是：

> 阻尼钢框架高漂移响应、屈服状态、损伤状态或极端尾部风险预测。

那么当前结果还不够。原因是当前最佳测试集没有 `>=0.010` 样本，`>=0.005` 的 F1 也只有约 `0.68`，而原始高尾部数据集上 `>=0.020` 区间存在严重低估。

### 4.3 推荐发表门槛

当前 `2dcnnv2/drop`：

- 对“整体响应快速估计”：基本足够；
- 对“高精度代理模型”：还需要和 XGBoost/LightGBM/CatBoost 等强基线比较；
- 对“高漂移风险预测”：不足，必须补高漂移 train/val/test 覆盖和 tail 指标。

建议目标线：

| 论文定位 | 建议指标 |
|---|---|
| 工程应用型、整体响应预测 | R2 >= 0.85，MAE <= 0.0010-0.0015，MAPE <= 25%，有清晰工程应用 |
| 较稳妥英文期刊 | R2 >= 0.90，MAE <= 0.0010，RMSE <= 0.0015，MAPE <= 20%，且有强基线/消融 |
| 主打高精度或风险预警 | R2 >= 0.94，`>=0.010` tail F1/Recall >= 0.80，分漂移区间无系统性低估 |

## 5. 其他论文通常比较哪些算法

同类结构响应代理模型论文常见算法如下。

传统与树模型：

- Linear Regression / Ridge / Lasso / Elastic Net；
- SVR / SVM；
- KNN；
- Decision Tree；
- Random Forest；
- Extra Trees；
- AdaBoost；
- Gradient Boosting / GBRT / GBR；
- XGBoost；
- LightGBM；
- CatBoost；
- Gaussian Process Regression。

神经网络与深度模型：

- ANN / MLP；
- 1D-CNN；
- LSTM / BiLSTM / GRU；
- TCN / WaveNet；
- Transformer / Seismic Wave Transformer；
- 2D-CNN on scalogram/spectrogram；
- CNN-LSTM / Conv1D-LSTM；
- Physics-informed NN 或带物理约束的混合模型。

辅助对比：

- 单模型 vs stacking/blending/aggregation；
- 只用结构参数 vs 结构参数 + 地震动强度指标；
- 只用标量特征 vs 标量 + 时频图；
- 不加权 loss vs tail-weighted loss；
- 无阻尼器布置特征 vs 有阻尼器布置特征；
- 未见地震波测试 vs 随机样本测试。

## 6. 建议本项目新增哪些对比算法

### 6.1 最小必须对比组

建议先做以下 6 类，足够支撑一篇工程应用型论文：

| 算法 | 输入 | 目的 |
|---|---|---|
| DummyMean / Linear 或 Ridge | 标量特征 | 给出最低基线，证明任务不是靠均值就能解决 |
| Random Forest | 63 个标量特征 + damper layout | 传统非线性树基线 |
| Extra Trees | 同上 | 检查随机树集成上限 |
| XGBoost | 同上 | 文献中最常见强基线之一 |
| LightGBM 或 CatBoost | 同上 | 当前结构响应代理论文常见强模型，CatBoost 很值得加 |
| MLP | 同上 | 与当前 CNN 的标量神经网络基线对比 |

### 6.2 深度学习对比组

如果要突出“地震波时频图 + 多模态融合”的贡献，建议再加：

| 算法 | 输入 | 用途 |
|---|---|---|
| 1D-CNN / TCN | 原始地震波时程 + 结构参数 | 对比 2D scalogram 是否真的有价值 |
| LSTM/GRU 或 WaveNet | 原始地震波时程 + 结构参数 | 对比时序建模能力 |
| 2D-CNN image-only | scalogram | 证明仅图像不足或图像贡献 |
| scalar-only MLP | 63 个标量特征 | 证明多模态融合相对标量模型的增益 |
| 当前 2D-CNN multimodal | scalogram + 标量 + damper layout | 主模型 |

### 6.3 Tail 专项对比

当前项目真正薄弱的是 tail。建议至少增加：

- XGBoost/CatBoost 的 `sample_weight` 版本；
- XGBoost/CatBoost 的 `log1p(y*1000)` 目标版本；
- 两阶段模型：先分类 `drift>=0.005/0.010`，再分别回归；
- Quantile Regression / 分位数 LightGBM，用于给出上分位预测；
- conformal prediction 区间，用来表达高响应不确定性。

## 7. 后续最优先修改

1. 重新构造分层数据集。train/val/test 都应覆盖 `>=0.005`、`>=0.010`、`>=0.020`、`steel01_yielded`、`steel02_yielded`、`num_floors` 和 `wave_cluster`。只保持 wave-level holdout 不够，还要保证响应区间也分层。
2. 训练前去重或明确重复样本的物理含义。当前原始 test 有 264 个重复 `sample_id`，drop test 有 4 个重复 `sample_id`。
3. 当前 drop 数据集中不应继续使用 `0.010/0.020/0.030` 作为主要 tail 分类阈值，因为训练集没有正样本。可临时改为 `0.003/0.005/0.007`；等高漂移样本恢复后再使用工程阈值。
4. 论文结果表必须同时报告全局指标和分区间指标。只报告 R2/MAE 会掩盖 `0.005-0.010` 和 `>=0.020` 的系统性低估。
5. 优先跑表格强基线。若 CatBoost/XGBoost 在标量特征上已经达到或超过当前 2D-CNN，则论文贡献应转向“多模态解释性、未见波泛化、tail-aware 策略和计算效率”，不能只说 CNN 精度更高。

## 8. 最终判断

当前应采用 `output/2dcnnv2/model-nostamp-6f475c7d-train20260601-014156` 作为主结果，但论文表述要克制：

- 可以说：在当前中低漂移测试集上，模型达到 `R2=0.9075`、`MAE=2.88e-4`，具备快速代理预测价值；
- 不应说：模型已经可靠解决高漂移或屈服后响应预测；
- 必须补充：强基线算法、消融实验、分漂移区间误差、tail recall/F1、未见波测试、数据分层说明。

`2dcnnv9` 的思路不是错误的，但当前 drop 数据集没有高尾部正样本，导致它的 tail 优化目标无法发挥作用。下一步不是继续堆更复杂网络，而是先把高漂移样本重新分层进 train/val/test，然后再评估 v9 或新的 tail-aware 版本。
