# lstmv1 实现说明

`lstmv1` 使用原始地震波时程与 63 维标量特征融合预测 `max_drift_ratio_raw`。

运行方式：

```powershell
uv run python lstmv1/lstmv1.py
uv run python lstmv1/lstmv1test.py
```

输出目录：

```text
output/lstmv1/model-<dataset_hash>-train<timestamp>
```

主要结构：

```text
Conv1d downsampling stem
BiLSTM
Attention pooling
Residual scalar encoder
Gated bilinear fusion
Tail-aware regression head
```
