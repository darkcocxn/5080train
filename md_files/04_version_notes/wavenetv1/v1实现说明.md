# wavenetv1 实现说明

`wavenetv1` 使用原始地震波时程与 63 维标量特征融合预测 `max_drift_ratio_raw`。

运行方式：

```powershell
uv run python wavenetv1/wavenetv1.py
uv run python wavenetv1/wavenetv1test.py
```

输出目录：

```text
output/wavenetv1/model-<dataset_hash>-train<timestamp>
```

主要结构：

```text
1x1 input projection
Dilated gated residual TCN blocks
mean / max / attention pooling
Residual scalar encoder
Gated bilinear fusion
Tail-aware regression head
```
