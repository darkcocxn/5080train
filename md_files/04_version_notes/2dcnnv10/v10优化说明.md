# 2dcnnv10 优化说明

## 设计目标

v10 继续沿用 v8 主训练流程的包装式结构，并在 v9 结果基础上做一次更有依据的调整。v9 的测试结果显示：

- `R2 / RMSE` 比 v8 略有改善。
- 默认 best checkpoint 选到了第 `5` 轮，训练明显偏早。
- `True_Drift >= 0.03` 的 severe tail 仍有显著低估。
- 小漂移区间 MAE 和 MAPE 被拉高，说明继续粗暴加权会伤到主体样本。

因此 v10 的核心不是继续堆大权重，而是采用“更晚选模 + 更平滑的密度权重 + 分位数式欠预测惩罚”。

## 参考依据

- Label Distribution Smoothing / Feature Distribution Smoothing：参考论文 `Delving into Deep Imbalanced Regression`。v10 将密度权重改为更平滑的 LDS 风格，减少长尾权重的跳变。
- Quantile Regression：参考 Koenker 和 Bassett 的分位数回归思想。v10 在尾部加入 `tau > 0.5` 的 pinball loss，让模型在极端样本上更不容易低估。
- PyTorch `WeightedRandomSampler`：官方文档要求传入的是每个样本的权重。v10 继续按样本构造权重，并把高层、低刚度、低强度作为样本级风险因子。
- PyTorch `SmoothL1Loss`：继续保留 v8 的主损失，避免极端误差直接主导全部训练。
- 社区工程经验：PyTorch 社区讨论中常见建议是采样权重和损失权重可以叠加，但需要裁剪和归一化。v10 相比 v9 降低了采样放大倍数，并用更晚的 checkpoint 选择来控制早期波动。

## 相比 v9 的主要改动

1. 延后默认 checkpoint 选择
   - 新增 `SELECTION_MIN_EPOCH = 30`
   - 前 30 轮的 selection score 加固定 offset，避免第 3-5 轮因为尾部偶然指标好而被选成默认 best

2. LDS 风格密度权重
   - 增加 `LDS_DENSITY_BIN_COUNT = 48`
   - 使用更宽的高斯平滑核：`kernel_size = 9`, `sigma = 1.6`
   - 目标是平滑长尾回归标签分布，而不是让少数区间权重突变

3. 分位数式尾部欠预测惩罚
   - `>=0.01` 使用 `tau = 0.60`
   - `>=0.02` 使用 `tau = 0.68`
   - `>=0.03` 使用 `tau = 0.76`
   - 这会在尾部更重地惩罚低估，同时仍保留对过高预测的约束

4. 更温和的采样权重
   - v9 的采样和损失都偏激，导致小漂移区间误差上升
   - v10 保留高层/低刚度/低强度风险因子，但降低采样 boost

5. 更长 early stopping patience
   - `EARLY_STOPPING_PATIENCE = 42`
   - 目的是让模型有机会越过 v9 的早期平台，接近 v8 中后期的总体拟合能力

## 可选环境变量

- `SURMOD_2DCNN_WEIGHTS_NAME`
  - 测试时强制指定某个权重文件名
- `SURMOD_2DCNN_POST_PROCESS_FACTOR`
  - 测试时给预测结果乘一个统一系数

## 预期效果

v10 预期会比 v9 更稳，重点观察：

- `best_epoch` 是否明显晚于 v9 的第 `5` 轮
- `True_Drift >= 0.03` 的 bias 是否减小
- `6-7` 层 MAE 是否下降
- 小漂移区间 `<0.005` 的 MAE 是否回落

如果 v10 仍低估 extreme tail，下一步建议加入验证集校准层，而不是继续单纯加大训练权重。
