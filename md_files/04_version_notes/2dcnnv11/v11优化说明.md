# 2dcnnv11 优化说明

生成日期：2026-06-01

## 1. 基础版本

`2dcnnv11` 基于当前最优主结果 `2dcnnv2` 创建，原始最优目录保持不动：

```text
output/2dcnnv2/model-nostamp-6f475c7d-train20260601-014156
```

v2 当前测试指标：

| R2 | MAE | RMSE | MAPE |
|---:|---:|---:|---:|
| 0.907476 | 0.000288331 | 0.000412856 | 17.16% |

## 2. 为什么需要 v11

当前 `drop-split-rank-top5drift` 数据集的真实分布是：

| split | `>=0.003` | `>=0.005` | `>=0.007` | `>=0.010` |
|---|---:|---:|---:|---:|
| train | 27180 | 9268 | 2054 | 0 |
| val | 888 | 422 | 259 | 152 |
| test | 521 | 143 | 17 | 0 |

v2/v9 原有 `0.010/0.020` tail 阈值在当前训练集中没有正样本。继续强化这些阈值没有实际学习信号，容易造成验证目标和测试目标失配。

因此 v11 的核心目标是：

1. 保留 v2 的稳定训练框架；
2. 对当前数据自动改用可学习的中高漂移阈值；
3. 轻度增强网络容量；
4. 增强 `0.005-0.010` 区间的低估抑制；
5. 不覆盖 v2 的最优结果。

## 3. 主要改动

### 3.1 数据自适应 tail 阈值

新增自适应策略：

```text
默认工程阈值: [0.005, 0.010, 0.020]
当前 fallback 阈值: [0.003, 0.005, 0.007]
```

当训练集中 `>=0.010` 的样本数低于 `96` 时，自动切换到 fallback 阈值。

当前数据会使用：

```text
TAIL_CLASSIFICATION_THRESHOLDS = [0.003, 0.005, 0.007]
VAL_MID_TAIL = 0.003-0.005
VAL_TAIL = >=0.005
VAL_EXTREME_TAIL = >=0.007
```

这样 tail 分类头、采样权重、验证选择和低估惩罚都有真实正样本可学。

### 3.2 更强但克制的模型容量

相比 v2：

| 模块 | v2 | v11 |
|---|---:|---:|
| CNN channels | `[32, 64, 128, 192]` | `[32, 72, 144, 224]` |
| CNN projector | 256 | 288 |
| Scalar embed | 160 | 192 |
| Scalar residual blocks | 3 | 4 |
| Fusion bilinear dim | 64 | 80 |
| Fusion output dim | 320 | 384 |
| Head hidden | `[320, 96]` | `[384, 128]` |
| 参数量 | 约 1.96M | 约 2.80M |

这个增幅是有意控制的：增强表达能力，但避免 v3 那种一次性叠加过多正则和增强导致训练退化。

### 3.3 中高漂移低估抑制

v11 在原 SmoothL1 + density weight + tail underprediction 的基础上增加：

- relative underprediction loss；
- tail pinball loss；
- 更平滑的 density label weighting；
- 针对 fallback 阈值的 sampler boost。

目的不是强行抬高所有预测，而是减少 `0.005-0.010` 区间的系统性低估。

### 3.4 独立输出目录

所有 v11 结果保存到：

```text
output/2dcnnv11
```

不会覆盖：

```text
output/2dcnnv2
output/2dcnnv9
```

## 4. 运行方式

训练：

```powershell
uv run python 2dcnnv11/2dcnnv11.py
```

测试：

```powershell
uv run python 2dcnnv11/2dcnnv11test.py
```

也可以使用：

```text
2dcnnv11/启动训练.bat
2dcnnv11/启动测试.bat
```

## 5. 预期观察指标

v11 是否真正优于 v2，不看训练 loss，而看测试集：

| 指标 | 目标 |
|---|---|
| 全局 R2 | 争取高于 0.9075 |
| 全局 MAE | 争取低于 0.000288 |
| 全局 RMSE | 争取低于 0.000413 |
| `>=0.005` F1 | 争取高于 0.68 |
| `0.005-0.010` 欠预测率 | 争取低于 81.8% |
| MAPE | 不应明显高于 17%-18% |

如果 v11 全局指标略降但 `>=0.005` F1 明显提升，可作为 tail-aware 对照版本；如果全局和 tail 同时提升，则可替代 v2 作为论文主结果。

## 6. 风险说明

当前测试集只有 17 条 `>=0.007` 样本，且没有 `>=0.010` 样本。v11 能改善当前数据上的中高漂移学习，但仍不能证明模型已经可靠预测极端漂移或屈服后响应。

若论文要主打高漂移风险预测，仍需重新构建分层数据集，让 train/val/test 都覆盖：

```text
>=0.010
>=0.020
steel01_yielded = 1
```

## 7. 已完成验证

- `python -m py_compile 2dcnnv11/2dcnnv11.py 2dcnnv11/2dcnnv11test.py` 通过；
- `uv run` 前向 smoke test 通过；
- v11 在模拟无 `>=0.010` 训练样本时会自动切换到 `[0.003, 0.005, 0.007]`；
- v11 模型前向输出维度为 `(batch, 1)`，tail logits 维度为 `(batch, 3)`。
