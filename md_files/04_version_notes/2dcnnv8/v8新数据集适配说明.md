# 2dcnnv8 新数据集适配说明

## 基线

v8 基于 `2dcnnv2` 复制而来，模型结构、训练损失、采样策略、EMA、验证指标和测试评估流程保持 v2 逻辑。

## 主要改动

1. 默认数据目录改为优先读取 `X:\pyproject\Remote-Train\newdata`。

   实际运行时按脚本所在仓库根目录解析为 `<项目根目录>\newdata`，不依赖 `X:` 盘符。远程训练机器只需要保持 `newdata` 位于项目根目录下。

2. 模型输出目录改为 `output\2dcnnv8`，避免覆盖 v2 训练结果。

3. 新数据集 CSV 的 `image_path` 列为空，v8 不再因为 `image_path` 为空而过滤样本。有效样本仍要求以下字段非空：
   `num_floors`, `floor_mass`, `floor_height`, `k_base_1_4`, `Fy_add`, `txt_path`, `max_drift_ratio_raw`。

4. 小波图路径不再依赖 CSV 的 `image_path`，而是通过数据库恢复对应关系：
   `newdata\Newdatabase\rare_waves_metadata.db`

5. `txt_path` 中的地震波引用格式为：
   `h5://.../rare_waves_scaled.h5|wave_id`

   v8 会从 `|` 后解析 `wave_id`，再查询数据库表 `wave_metadata` 的 `scalogram_path` 字段，得到对应小波图，例如：
   `Newdatabase/Scalogram/rare_waves-20260531-140353/23.png`

6. 训练元数据 `training_metadata.json` 额外记录数据库路径和映射字段：
   `wave_metadata_db_path`, `wave_metadata_table`, `wave_metadata_id_col`, `wave_metadata_scalogram_col`。

7. `training_metadata.json` 中的 CSV、小波图目录和 db 路径会尽量保存为相对项目根目录的路径；测试脚本读取旧绝对路径时，也会优先回退到当前仓库下的 `newdata`。

8. 如果远程机器的数据目录不在项目根目录下，可以用环境变量覆盖：
   `SURMOD_NEW_DATA_DIR`, `SURMOD_WAVE_METADATA_DB`, `SURMOD_WAVELET_IMAGE_DIR`。

## 脚本

- 训练：`2dcnnv8\2dcnnv8.py`
- 测试：`2dcnnv8\2dcnnv8test.py`
- 启动训练：`2dcnnv8\启动训练.bat`
- 启动测试：`2dcnnv8\启动测试.bat`

## 注意事项

测试脚本会读取训练产生的 `training_metadata.json`，并使用同一套小波图数据库映射。建议远程训练时保留 `newdata\Newdatabase` 的相对目录结构；若目录不同，用上面的环境变量覆盖。
