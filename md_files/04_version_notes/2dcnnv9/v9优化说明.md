# 2dcnnv9 优化说明

## 核心方向

v9 不是重新复制一份 v8 主体代码，而是在 v8 训练/测试流程上做补丁式增强，重点针对 v8 暴露出来的几个问题：

- `6-7` 层与大漂移尾部样本误差偏大
- `True_Drift >= 0.02` 时存在系统性低估
- 默认 best checkpoint 更偏总体 MAE，而不是更保守的尾部表现

## 训练侧改动

1. 更强的尾部采样
   - 提高 `>=0.01`、`>=0.02`、`>=0.03` 样本的采样 boost
   - 额外提高高层、低刚度、低屈服强度样本的采样概率

2. 更强的尾部损失
   - 增加 `>=0.03` 的 severe tail 权重
   - 在欠预测惩罚里加入相对误差项，不只看绝对误差

3. 更细的尾部分类辅助头
   - 分类阈值从 `[0.01, 0.02]` 扩展到 `[0.01, 0.02, 0.03]`

4. 更保守的验证选择分数
   - 提高 tail / extreme tail / severe tail 的权重
   - 对负偏差，也就是低估，单独增加惩罚

## 默认权重选择

训练结束后，v9 会在以下候选权重之间再做一次保守筛选：

- `best_2dcnn_model.pth`
- `best_2dcnn_focus_model.pth`
- `best_2dcnn_mae_model.pth`
- `best_2dcnn_extreme_under_model.pth`

然后把更适合默认评估的权重写回 `training_metadata.json` 的 `best_weights_name`。  
这样测试脚本默认就会优先加载更保守的那份权重，而不是只看总体 MAE。

## 脚本

- 训练：`2dcnnv9/2dcnnv9.py`
- 测试：`2dcnnv9/2dcnnv9test.py`
- 启动训练：`2dcnnv9/启动训练.bat`
- 启动测试：`2dcnnv9/启动测试.bat`

## 可选环境变量

- `SURMOD_2DCNN_WEIGHTS_NAME`
  - 测试时强制指定某个权重文件名
- `SURMOD_2DCNN_POST_PROCESS_FACTOR`
  - 测试时给预测结果乘一个统一系数
